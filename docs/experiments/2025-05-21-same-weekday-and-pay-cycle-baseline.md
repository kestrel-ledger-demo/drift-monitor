# Same weekday and pay cycle baseline

Date: 2025-05-21
Who: Marc Gagnon, Ahmed Siddiqui
Uncertainty: U1 Drift without fraud labels

## Plan (written before the run)

Hypothesis: Comparing to the same weekday in the same pay cycle removes payday alarms.
What changes: Baseline changed from last month to matched calendar days.
Setup: Same 12 months, Canadian pay cycles (biweekly, semi-monthly).

## Result (written the same day)

Result: False alarms down from 17 to 6; both waves caught, one 3 days late.
Learned: Calendar matching works; detection is still late for slow-building waves.
Outcome: Partly worked
